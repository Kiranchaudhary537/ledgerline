# Folder structure

Code is grouped by **feature**, not by file type. Tests sit next to the code (`x.ts` → `x.test.ts`).

```
apps/
  api/                      Fastify: routes, auth, business logic
    src/
      app.ts                builds the app: repositories → services → routes, wired once
      server.ts             starts listening
      env.ts                env vars, checked by Zod at boot
      errors.ts             AppError + error handler (→ error-handling.md)
      plugins/              db, session auth, rate limit
      modules/
        auth/               routes.ts · service.ts (AuthService)
        employees/          routes.ts · service.ts (EmployeeService) · csv.ts
        insights/           routes.ts · service.ts (InsightsService)
        meta/               routes.ts · service.ts (MetaService, filter lists)
        health/             routes.ts
      (tests sit next to the file they cover: service.test.ts uses fake repositories,
       routes.db.test.ts uses the test database. Shared helper: src/testing.ts)
  web/                      React + Vite + shadcn
    src/
      main.tsx · router.tsx
      lib/api.ts            fetch wrapper → returns data or throws ApiError
      components/ui/        shadcn primitives
      components/           app-wide pieces (layout, empty state, error banner)
      features/
        auth/               login page, session hook
        employees/          list page, detail page, forms, hooks

packages/
  shared/                   used by api AND web
    src/
      validation/           Zod: employee, salary-change, list-query, insights, auth
      config.ts             every tunable value (page sizes, session, rate limits, seed, thresholds)
      errors.ts             error codes + default messages
      money.ts              minor units ↔ display
      constants.ts          countries (from `countries-list` + `Intl`), levels, employment types, genders
  db/                       everything that touches Postgres
    src/
      client.ts             Kysely instance
      types.ts              table types (generated by kysely-codegen – do not edit)
      migrations/           001 initial · 002 departments + job titles (composite FK on employees)
      repositories/         EmployeeRepository · InsightsRepository · SessionRepository ·
                            UserRepository · DepartmentRepository · filters.ts (employeeFilters)
      password.ts           scrypt hash/verify
      testing.ts            test DB helpers
      seed/                 index.ts · generate.ts · seed.ts · data.ts (departments and titles, names per country, salary bands)

docs/
docker-compose.yml · pnpm-workspace.yaml · tsconfig.base.json · .env.example
```

## Dependency rule

```
web ──► shared
api ──► shared, db
db  ──► shared
```

- `shared` depends on nothing.
- Only `db` writes SQL.
- `web` never imports `api` or `db`.
